# **App Name**: AuraGrid Sentinel

## Core Features:

- Grid State Dashboard: Visualize real-time or simulated grid frequency deviation, response latency, and aggregated Virtual Power Plant (VPP) actions and energy metrics in an intuitive dashboard.
- Virtual Power Plant Configuration: Provide a user interface to configure parameters for the simulated VPP and observe aggregated control signals to edge devices.
- Forecasting Visualizer: Display probabilistic solar forecasting data for specific transformers, visualizing predicted cloud-shading events and their associated lead times.
- Simulated Event Injector: Allow users to inject simulated frequency dips, sudden load changes, or 'demand-side attack' patterns to test the VPP agent's autonomous response.
- Generative AI Grid Assistant Tool: An AI tool that analyzes complex grid data, forecasts, and VPP response patterns to provide human-understandable explanations for system behavior, identify potential threats, or suggest proactive measures for grid stability.
- Historical Data Explorer: Enable browsing and analysis of past simulated grid performance data, VPP actions, and event logs from various scenarios to review system resilience.

## Style Guidelines:

- The application will utilize a dark color scheme to foster concentration and convey a high-tech monitoring environment. The primary color will be a deep, confident blue ('#2275A9'), reflecting stability and data flow. The background will be a desaturated, very dark blue-grey ('#1F262B'), creating a clear contrast. An energetic, vibrant purple-blue ('#6B6BF5') will serve as an accent for calls to action, alerts, and highlighting critical data points.
- Headlines and prominent display text will use 'Space Grotesk' (sans-serif) for its modern, slightly technical aesthetic, aligning with the scientific nature of grid analysis. Body text, labels, and detailed information will employ 'Inter' (sans-serif) to ensure excellent readability and clarity for dense data presentations.
- Modern, crisp line icons will be used throughout the interface. Icons will abstractly represent concepts such as power flow, data metrics, grid stability, warning indicators, and individual edge devices, maintaining a clean and cohesive visual language.
- The layout will prioritize a dashboard-centric approach, featuring modular panels for different data visualizations and control interfaces. Information hierarchy will be meticulously crafted to guide the user's attention to critical grid status and alerts first. The design will be responsive to ensure usability across various screen sizes.
- Subtle and purposeful animations will enhance user experience, such as smooth transitions between data states, dynamic updates to real-time metrics (e.g., slight pulse on new data), and elegant loading indicators that convey progress without distraction. Emphasis will be on conveying dynamism and responsiveness of the grid.
